# Power BI Pizza Sales Dashboard

An interactive Power BI portfolio project focused on exploring pizza sales data and presenting business information through a visual report.

## Project file

- **Final_Bi_Project.pbix** — Open this file with Microsoft Power BI Desktop to view and interact with the report.

## Tools and technologies

- Microsoft Power BI Desktop
- Power Query (data preparation, if used in the report)
- DAX (measures and calculations, if used in the report)
- Data visualization

## How to open

1. Install Microsoft Power BI Desktop.
2. Download `Final_Bi_Project.pbix`.
3. Open the file in Power BI Desktop.
4. If Power BI asks for data-source credentials or a file path, update the source settings to match your local dataset.
